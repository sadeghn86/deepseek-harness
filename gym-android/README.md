# مدیریت باشگاه — برنامهٔ اندروید آفلاین

یک برنامهٔ اندرویدی **کاملاً آفلاین** برای مدیریت اعضای باشگاه: ثبت عضو،
تاریخ اتمام عضویت به **تاریخ شمسی**، اعلان رسیدن زمان شهریه، و جدولی که
تعداد نفرات را در هر وضعیت نشان می‌دهد.

هیچ دسترسی اینترنتی در `AndroidManifest.xml` اعلام نشده است؛ داده‌ها فقط در
یک فایل SQLite داخل حافظهٔ گوشی ذخیره می‌شوند.

## امکانات

- **جدول اعضا** با ستون‌های نام / موبایل / پایان عضویت / وضعیت، همراه با
  کارت‌های شمارش بالای جدول: **کل اعضا، فعال، نزدیک اتمام، منقضی** و یک خط
  خلاصهٔ «تعداد نفرات».
- **بخش افزودن عضو**: نام، موبایل، بستهٔ عضویت (ماهانه تا سالانه)، شهریه،
  **تاریخ شروع** و **تاریخ اتمام** با انتخابگر تاریخ شمسی، و توضیحات.
  با عوض شدن بسته، تاریخ اتمام خودکار حساب می‌شود.
- **اعلان شهریه**: یک آلارم روزانه (AlarmManager) اعضایی را پیدا می‌کند که
  در N روز آینده عضویتشان تمام می‌شود یا تمام شده، و اعلان می‌فرستد.
  از داخل خود اعلان هم می‌شود یک دوره تمدید کرد.
- **ارسال پیامک**: متن آمادهٔ یادآوری شهریه با تاریخ اتمام ساخته می‌شود و
  برنامهٔ پیامک گوشی باز می‌شود (بدون اینترنت).
- جست‌وجو بر اساس نام یا موبایل + فیلتر بر اساس وضعیت.
- رابط راست‌به‌چپ و ارقام فارسی.

## ساختن APK

```bash
cd gym-android
gradle assembleDebug          # یا: ./gradlew assembleDebug اگر wrapper دارید
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

نیازمندی‌ها: JDK 17، Android SDK با `platforms;android-34` و
`build-tools;34.0.0`، Gradle 8.7.

اجرای تست منطق تاریخ و یادآوری:

```bash
cd gym-android && gradle testDebugUnitTest
```

## CI

`gym-android/ci/gym-apk.yml` را در `.github/workflows/gym-apk.yml` کپی کنید
(بیلد باید زیر `.github/workflows/` باشد تا گیت‌هاب اجرا کند). بعد از آن با هر
push که `gym-android/**` را تغییر بدهد اجرا می‌شود، تست‌ها را می‌گیرد، هر دو APK را می‌سازد و آن‌ها را به‌صورت
artifact و یک prerelease منتشر می‌کند.

## ساختار

| مسیر | نقش |
| --- | --- |
| `JalaliDate.kt` | تبدیل میلادی ↔ شمسی، طول ماه، کبیسه، محاسبهٔ دورهٔ عضویت (بدون وابستگی به اندروید) |
| `DbHelper.kt` | جدول `members` در SQLite + شمارش‌ها + فهرست اعضایی که اعلان می‌خواهند |
| `Member.kt` | مدل عضو، وضعیت (فعال/نزدیک اتمام/منقضی)، پرچم اعلان، بسته‌ها |
| `MainActivity.kt` | کارت‌های شمارش + جدول + جست‌وجو و فیلتر |
| `MemberActivity.kt` | فرم افزودن/ویرایش، تمدید، ارسال پیامک |
| `JalaliDatePickerDialog.kt` | انتخابگر تاریخ شمسی با سه چرخ‌دنده |
| `ReminderScheduler.kt` | زمان‌بندی بررسی روزانه با AlarmManager |
| `ReminderReceiver.kt` | ساختن اعلان‌ها و تمدید سریع از داخل اعلان |
| `SettingsActivity.kt` | چند روز قبل، چه ساعتی، روشن/خاموش، اعلان آزمایشی |
